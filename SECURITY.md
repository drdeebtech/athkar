# Security Policy

## Supported versions

Security fixes are applied to the latest version of the `main` branch, which is
what runs on https://athkar.site.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub:
[Report a vulnerability](https://github.com/drdeebtech/athkar/security/advisories/new)

Include the affected URL or file, steps to reproduce, and the impact you expect.
You will get an acknowledgement within a few days.

## Scope

- Code and configuration on the `main` branch of this repository
- The deployed site at athkar.site and www.athkar.site

Out of scope: third-party services (Cloudflare, GitHub, Google AdSense) and
issues that require a compromised device or browser.
